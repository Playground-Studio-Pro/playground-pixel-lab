# Project Context

## Problem

Preparing an LED show means turning cabinets and screen layouts into exact pixel coordinates, then re-entering them in the media server and handing templates to content creators. Done by hand, one wrong pixel shows up on the wall during load-in.

## Intended User

LED and video technicians at Playground Studio, an audiovisual production company. Later, other production companies as paying SaaS customers.

## Business / Product Objective

A focused production tool first, expanding deliberately toward a broader LED engineering platform.

## Current Scope

Projects, cabinet library, screen designer, three-layer mapping engine, exports (PNG, SVG, JSON, report), and a Resolume preparation package with a manual setup guide.

## Known Constraints

- Local-only storage for now, with architecture ready for cloud sync.
- No billing, accounts or enterprise features in the MVP.
- Resolume's preset format is undocumented. See RESOLUME.md.
